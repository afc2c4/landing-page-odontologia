# 🦷 Sorriso Radiante — Landing Page Odontológica (Mobile-First)

Este documento descreve detalhadamente a estrutura, componentes, tecnologias e fluxos de conversão presentes no arquivo `index.html`.

---

## 📌 Visão Geral

A landing page foi desenvolvida para clínicas e consultórios odontológicos com foco em:
1. **Acolhimento humanizado** para pacientes com receio de ir ao dentista (ênfase em "atendimento sem dor").
2. **Conversão direta via WhatsApp** em múltiplos pontos de contato ao longo da navegação.
3. **Experiência Mobile-First nativa**, priorizando o uso do polegar, carregamento ágil e toques rápidos.
